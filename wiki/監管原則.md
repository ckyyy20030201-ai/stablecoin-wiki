# 監管原則

**一句話定義：** BIS 建議各國管理穩定幣時應遵守的共同原則，也是後面比較各國法規的基準。（來源：[[sources/S1-BIS]]）

## BIS 的建議
1. **同樣活動、同樣風險、同樣監管結果**：不因為用了新技術就放寬或加嚴。（來源：[[sources/S1-BIS]]）
2. **完整性優先**：託管錢包要做 KYC、落實旅行規則（travel rule）、用鏈上分析追蹤並凍結不法資金。（來源：[[sources/S1-BIS]]）
3. **準備與透明**：要求高品質、高流動性的準備資產，定期審計並公開揭露。（來源：[[sources/S1-BIS]]）
4. **本地授權**：發行人須在當地取得授權並設立公司。（來源：[[sources/S1-BIS]]）
5. **國際協調**：避免業者往監管最寬鬆的地方跑（監管套利）。（來源：[[sources/S1-BIS]]）
6. **限制付息**：部分地區禁止向持有人支付利息。（來源：[[sources/S1-BIS]]）

## 各國做法：對照 BIS 原則
| BIS 原則 | 美國 | 歐盟 | 香港 | 台灣 |
|---|---|---|---|---|
| 準備與透明 | ✓ 1:1 高品質準備、揭露、審計 | ✓ 準備分離保管、依面額贖回 | ✓ 準備分離、資本要求、揭露 | 百分百準備（媒體報導） |
| 完整性優先（洗錢防制） | ✓ 適用銀行秘密法 | 資料未涵蓋 | 資料未涵蓋 | ✓ 由登記制提升為許可制 |
| 本地授權 | ✓ 須取得執照；外國發行人須向 OCC 註冊 | ✓ 須在歐盟取得授權 | ✓ 須在香港有主要營業地點 | ✓ 須金管會許可 |
| 限制付息 | ✓ 禁止付息 | ✓ 禁止付息 | 資料未涵蓋 | 資料未涵蓋 |
